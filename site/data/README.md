# `watchlist.json` — data for `watchlist.html`

Generated by `scripts/export_watchlist_data.py` (logic in `ingestion/watchlist_export.py`) and by the
Airflow DAG's final task, `export_watchlist`, on every run. One record per FDIC-insured bank scored
in the latest quarter. Compact JSON (no spaces, short keys, rounded numbers), kept under 3 MB; the
export validates the structure below before writing.

Source tables (Snowflake `BANK_HEALTH.MARTS`):

| Table | Used for |
|---|---|
| `MART_EARLY_WARNING` | probability, risk band, reasons, complaints, model name/version, data quarter |
| `DIM_BANK` | established date (bank age), CFPB match flag |
| `MART_BANK_SCORECARD` | last 8 quarters of ratios per bank; peer medians by asset-size tier |

## Top level

```json
{ "meta": { ... }, "peers": { "1": { ... }, ... }, "banks": [ { ... }, ... ] }
```

## `meta`

| Key | Type | Meaning |
|---|---|---|
| `schema` | int | Schema version (currently 1) |
| `quarter` | string | Data quarter-end, `YYYY-MM-DD` |
| `quarterLabel` | string | e.g. `2026 Q2` |
| `exported` | string | Export date, `YYYY-MM-DD` |
| `model` | string | Registered model name |
| `modelVersion` | int | Model version that produced the scores |
| `banks` | int | Number of records in `banks` |
| `history` | string[8] | Quarter labels for every history array, **oldest first** |
| `metrics` | object | For each history key: `label`, `unit`, `higherIsBetter` (`null` = neither) |
| `bands` | object | Band code → band name |
| `newBankYears` | number | Age below which a bank is flagged as new (3) |

## `peers`

Keyed by asset-size tier (`"1"`…`"5"`, see `t` below). Each tier has the same five history keys
as a bank (`ncl`, `t1`, `roa`, `eff`, `dep`), each an array of 8 **median** values across all banks
in that tier for each quarter in `meta.history`. The page draws them as the reference line for a
bank, using the bank's current tier.

## `banks[]`

| Key | Type | Meaning |
|---|---|---|
| `c` | int | FDIC certificate number (CERT), unique |
| `n` | string | Bank name |
| `ci` | string | City |
| `st` | string | State code |
| `a` | number | Total assets, **$ millions**, 1 decimal |
| `age` | number \| null | Years since established, at the data quarter, 1 decimal |
| `nb` | 1 | Present only for banks younger than `meta.newBankYears`: ratios distorted by start-up costs (review finding M-02) |
| `t` | int | Asset-size tier: 1 `<$100M`, 2 `$100M–$1B`, 3 `$1B–$10B`, 4 `$10B–$100B`, 5 `>$100B` |
| `p` | number | Probability of distress or failure in the next 4 quarters, 3 decimals |
| `b` | string | Risk band: `H` High (top 5%), `E` Elevated (next 10%), `W` Watch (next 25%), `L` Low, `D` Already in distress (not ranked) |
| `pp` | int \| null | Percentile of `p` among banks in the same tier, 0–100 (share of same-size banks with a lower probability). `null` for band `D` |
| `r` | string[≤3] | Top reasons in plain words, e.g. `Non-current loans: 2.73% of loans (typical bank: 0.46% of loans)` |
| `h` | object | Last 8 quarters, aligned with `meta.history`, oldest first, `null` where not reported: `ncl` non-current loans % of loans, `t1` Tier 1 leverage %, `roa` return on assets %, `eff` efficiency ratio %, `dep` deposit growth year on year %. 2 decimals |
| `cx` | int | Complaints in the data quarter. Present only if the bank was matched to CFPB complaints |
| `cr` | number | Complaints per $1bn of deposits in the data quarter, 2 decimals. Present only if matched |

`banks` is sorted by `p`, highest first.

A screening tool on public data, not a supervisory rating.
